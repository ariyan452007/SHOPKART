# ShopKart Frontend

React 19 + Vite + Tailwind single-page app. See the [root README](../README.md) for setup, architecture and deployment.

```bash
npm install
npm run dev     # http://localhost:5173 (uses VITE_API_URL from .env)
npm run build   # production build in dist/ (calls /api, proxied by Netlify)
```
